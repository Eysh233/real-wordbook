# Real Wordbook · 真实单词本

一个运行在 Windows 上的本地背单词程序：主界面像一本真正的纸质笔记本，一页 9 行权重（日期行占半行）、每行 5 个词、按日期分页；可以登记单词、手绘感标注、调用 DeepSeek 解释、一键加权抽背，并导入标准化单词书追踪记忆进度。

```
┌───┬──────────────────────────────────────────────┐
│ ○ │  2026-10-28 周三 · 今日登记 12 词             │
│ ○ │  abandon      │  brief        │  …  共 5 列  │
│ ○ │  /əˈbændən/   │  /briːf/      │              │
│ ○ │ ──────────────────────────────────────────   │
│ ○ │              P. 1 / 8                        │
└───┴──────────────────────────────────────────────┘
```

## 功能

- **纸页笔记本**：一页 9 行权重（日期行半行，30 词常能一页放下）、每行 5 词，按登记日期自动分节并标注日期；页脚显示词数与页码，`‹ ›`、滚轮、方向键翻页。
- **登记与编辑**：`＋ 登记`（Ctrl+N）写入「我的单词本」，默认抽背权重 3；点击词条可编辑、删除。
- **标注 / 划线**：点击词条 → 手绘感黄色荧光笔（权重 6）或细横线压字（权重 1），再点一次取消。
- **AI解释**：调用 DeepSeek（`deepseek-flash`，`reasoning_effort=low`，JSON 输出），展示释义、构词、搭配、易混词、例句与记忆提示；结果按词缓存，未配置 Key 时其余功能照常。
- **抽背**：按权重加权随机（Efraimidis–Spirakis）出英文，点「显示中文」才揭晓；认识 / 不认识进入 SRS 阶梯（1/3/7/15/30/60 天）。
- **中英切换**：顶栏一键切换 中英 / 英 / 中。
- **单词书**：`StudyBook/*.md` 导入后单独存放，不会自动进入「我的单词本」；可选按编号顺序或随机顺序背诵，可只背未显示过 / 只背已登记的词，逐词记录「已显示 / 已显示并登记」。
- **扩展**：拼写测试、词根聚合、CSV 导入导出、12 周学习热力图、桌面迷你悬浮窗、三种纸张主题（米白 / 护眼绿 / 暗色）与字号缩放。

## 目录结构

```
app/           应用包（config / models / storage / repositories / services / ui）
docs/          设计文档
StudyBook/     导入的单词书（md）
StudyRecord/   每个单词书的记忆进度（json）——个人数据，不入库
data/          运行时数据（我的单词本、设置、AI 缓存）——不入库
tests/         离屏冒烟测试、演示数据与截图脚本

```

## 运行

```bash
# 依赖：Python 3.8+、PyQt5（本机已装 5.15.9）
pip install -r requirements.txt
python main.py

# 生成一份演示词库（可选，写入 data/ 与 StudyRecord/）
python tests/seed_demo.py

# 离屏冒烟测试（不弹窗，等价于一遍人工回归）
python tests/smoke_ui.py
```

## 数据与密钥

- **API Key 只存** `%USERPROFILE%\.real_wordbook\config.json`，或被环境变量 `DEEPSEEK_API_KEY` 覆盖；**永不写入仓库**。
- 我的单词本 `data/words.json`、设置 `data/settings.json`、AI 缓存 `data/ai_cache.json` 均在 `.gitignore` 内。
- 单词书 md 入库以便版本管理；记忆进度按需入库（见 D2）。

## 设计要点

- **纸感**：米白纸页、装订脊螺旋孔、行分隔细线、黑体单词（`Segoe UI`）、页脚页码。
- **标注即权重**：默认 3；黄色荧光笔 → 6；细横线压字 → 1。抽背按权重加权随机（Efraimidis–Spirakis，无放回）。
- **AI 是插件**：未配置 Key 时全部功能可用；请求走工作线程，结果按词缓存。
- **数据是我的**：纯本地 JSON / Markdown，可 diff、可手改、可带走。

## 提交与推送

本机直连 `github.com` 会被重置，已在本仓库 `.git/config` 内配置 HTTP 代理 `http://127.0.0.1:7897`（Clash 混合端口）。若代理端口变化：

```bash
git config --local http.proxy http://127.0.0.1:<PORT>
# 或临时直连
git config --local --unset http.proxy
```

首次推送需要 GitHub 身份认证（浏览器弹窗或 PAT），由本机 Credential Manager 记住：

```bash
git push -u origin main
```

之后每次 `git push` 不需要再输入。
