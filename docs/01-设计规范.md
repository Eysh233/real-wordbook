## 1. 项目目标

### 1.1 一句话定义

一个运行在 Windows 上的**本地桌面背单词程序**：主界面以「真实纸质笔记本」为隐喻呈现我的单词本，支持登记单词、手绘感标注、AI 解释、一键抽背，以及导入标准化单词书并跟踪记忆进度。

### 1.2 设计意图（为什么这样做）

- **纸感优先**：背单词是长时段、低刺激的重复劳动，界面越像纸，眼睛越不容易累，也越不容易被"软件感"打断。所有视觉与动效决策服从这条。
- **一处登记，多路复用**：我登记的单词（我的单词本）、导入的单词书（StudyBook）、抽背队列、AI 缓存共享同一套数据模型，避免"背过的词在另一个模块里查不到"。
- **权重可见可改**：抽背概率由权重驱动，而权重必须能被我在界面上理解（为什么这个词老出现？因为它是划线词……不，划线是降权）。因此权重既要参与算法，也要在 UI 上以极小代价可见。
- **AI 是插件，不是主轴**：没有 API Key 时全部功能可用，只是少一个按钮的解释结果。绝不允许 AI 调用阻塞主线程。
- **数据是我的**：全部落到本地可读文件（JSON / Markdown），无账号、无云依赖，随时可以拷走、diff、手改。

### 1.3 目标用户与使用场景

| 场景 | 频率 | 关键诉求 |
| --- | --- | --- |
| 阅读中遇到生词，立刻登记 | 每天多次 | 登记要快（≤2 次点击），不打断阅读 |
| 翻看自己的单词本，回看标注 | 每天 | 纸感、可翻页、能一眼看到当天日期分节 |
| 抽背已登记单词 | 每天 | 只需按键就出词，答案要"点一下才出现" |
| 导入一本新单词书并按顺序背 | 每周 | 顺序/随机、只背未显示过的、进度可续 |
| 查词义/例句/搭配 | 按需 | AI 一次解释，结果本地缓存复用 |

### 1.4 成功标准（可验收）

1. 冷启动 ≤ 1.5 s（1000 词规模），翻页与点击反馈 ≤ 100 ms 可见响应。
2. 一页 9 行槽、每行 5 词、页脚显示 `P.x / y`，页内按日期分节并标注日期与本日登记数。
3. 登记一个单词的完整操作 ≤ 2 次点击 + 1 次回车，落盘后重启程序不丢。
4. 标注/划线后重新抽背 100 次，标注词出现频次显著高于普通词、划线词显著低于普通词（可统计验证）。
5. 抽背中答案默认隐藏，必须点击「显示中文」才出现。
6. 一键切换 中 / 英 / 中英 三种显示，刷新后记住上次选择。
7. 导入 `docs/02` 规范格式的 md 单词书后，可在「开始背书」中选择顺序/随机，并选择「只背未显示过 / 只背登记过」。
8. 每个单词书的 `seen` / `registered` 状态写入 `StudyRecord/` 独立文件，重开可续。
9. 仓库中不存在任何真实 API Key（`git log -p` 与工作区双重检查）。

## 4. 界面设计（Apple 设计原则映射）

设计基线来自已安装的 `apple-design` skill：**响应（Response）、直接操控（Direct manipulation）、可中断（Interruptibility）、以行为代替动画（Spring）、空间一致性、材质与层次、排版细节、克制动效**。下表把每条原则落到本程序的具体控件。

| 原则 | 在本程序中的落点 |
| --- | --- |
| Response：按下即反馈 | 词格 `mousePressEvent` 立刻 `scale 0.98` + 阴影收起（≈100 ms），不等 `release` |
| 直接操控 | 拖拽选中多词格时 1:1 跟随指针，起点保持抓取偏移 |
| 可中断 | 抽背浮层可随时 `Esc` 或点击遮罩关闭；翻页动画中途再按方向键时，从当前位移续接 |
| Spring 而非固定时长 | 浮层出现：`damping 0.85 / response 0.28`；页切换：`damping 1.0 / response 0.34` |
| 空间一致性 | 操作浮层从被点击词格的位置展开（`transform-origin` 等价：按词格中心计算弹出点），关闭时沿同一路径收回 |
| 材质与层次 | 顶部工具条为半透明浮层，内容从其下方滚过；纸页有微弱内阴影，浮层比纸页"更高一层"（阴影更重） |
| 排版 | 单词用衬线体（Georgia / Times New Roman 回退），中文用系统 UI 字体；标题负字距、正文 0 |
| 克制 | 只有"揭示答案""翻页""标记成功"三种时刻给动效；滚动、悬停不做花活 |
| 无障碍 | `减少动效` 开关 → 全部过渡降级为 120 ms 淡入；对比度 ≥ 4.5:1（纸色 #FBF7EE 上的文字 #2B2722） |

### 4.1 窗口结构

```
┌──────────────────────────────────────────────────────────────┐
│  [浮动工具条: 我的单词本 | 单词书 | ＋登记 | 抽背 | 中/英/中英 | 🔍 | ⚙] │ ← 半透明，content 从下方滚过
│ ┌───┬──────────────────────────────────────────────────────┐ │
│ │ ○ │  2026-10-28 周三 · 今日登记 12 词                     │ │ ← 日期行
│ │ ○ │  abandon            │  brief             │ ... 5 列  │ │
│ │ ○ │  /əˈbændən/ n. 放弃  │  ...               │           │ │
│ │ ○ │ ─────────────────────────────────────────            │ │ ← 行分隔（细横线）
│ │ ○ │  ... 共 9 个行槽 ...                                  │ │
│ │ ○ │                                                      │ │
│ │ ○ │                    P. 1 / 8                          │ │
│ └───┴──────────────────────────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────┘
  装订脊：宽 64px，纸色更深，8 个螺旋孔，右缘 1px 内阴影
```

- 窗口默认 1180 × 840，最小 980 × 700；可缩放，纸页按比例伸缩，行槽数固定为 9 行（视觉密度优先于塞更多词）。
- 顶部工具条高 56 px，`rgba(255,255,255,0.62)` + 轻模糊（QGraphicsBlurEffect 或"多层半透明描边"近似），底部 1 px 高光。
- 底部页码条浮于纸页内，不占布局。

### 4.3 词格布局

- 每行 5 列等宽：`col = (page_width - 2*padding - 4*gap) / 5`，`padding=44`，`gap=12`。
- 词格内容（中英模式）：第一行 `单词`（衬线 17px，可截断），第二行 `音标`（11px, ink-soft），第三行 `词性 + 中文`（12.5px）。
- 英文模式：只留单词 + 音标（垂直居中）；中文模式：只留 `词性 + 中文`（居中，字号 +1）。
- 词格无边框、无底色，仅靠排版与行距成型；悬停时出现极浅底色 `rgba(0,0,0,0.03)`（120 ms 淡入）。

### 4.4 操作浮层（点击单词后）

- 尺寸随内容，宽 ≥ 240 px，锚定词格中心；若贴近窗口边缘则翻转到词格另一侧（同一路径进入/退出）。
- 顶部显示单词本身（可选中复制），下方按钮列表：`标注`（切换，已标注时显示 ✓）、`划线`、`AI 解释`、`编辑`、`删除`。
- `AI 解释` 点击后：浮层就地扩展为面板（不新开窗口），先显示骨架条 → 流式渲染各段落 → 底部 `复制`/`重新生成`/`关闭`。
- 关闭：`Esc`、点击遮罩、再次点击同一词格。

### 4.5 抽背浮层

- 全屏遮罩 `rgba(30,25,18,0.35)` + 居中卡片（560 × 360，纸色）。
- 卡片内容：`第 3 / 45`（左上）、`权重 ●3`（右上，小圆点数量 = 权重/3 取整 +1）、大字英文（40px 衬线）、下方 `显示中文` 按钮。
- 揭示后：中文淡入（180 ms），按钮变为 `下一个`；底部小字 `Esc 退出`。
- 键盘：`Space` = 显示/下一个，`Esc` = 退出，`1` = 认识（扩展），`2` = 不认识（扩展）。

### 4.6 手绘感标注绘制规范

**荧光笔（标注）**
1. 沿文字行框外扩 2 px，生成一条从 `x0` 到 `x1` 的闭合路径；
2. 上下边界各取 6 个控制点，使用**以单词 id 为种子的伪随机抖动**（±1.6 px）——同一单词每次渲染抖动一致，不闪烁；
3. 起笔端斜切（倾斜 -8°），收笔端略钝；
4. 填充 `highlight`，`CompositionMode_Multiply` 叠加，端部透明度 0.55 → 中间 0.8（模拟笔压）；
5. 允许超出文字 2–3 px，不允许覆盖相邻词格。

**划线**
1. 基线取文字底部 + 3 px，长度 = 文本宽 + 左右各 2 px；
2. 用 3 段贝塞尔模拟手写微抖（±0.8 px），线宽 1.2 px，颜色 `strike`；
3. 单词与中文各划一条（若中文换行则逐行划）；
4. 已划线词再次点击"划线"即取消，权重回落 3。

### 4.7 动效清单（含"减少动效"降级）

| 时刻 | 正常 | 减少动效 |
| --- | --- | --- |
| 词格按下 | scale 0.98，100 ms | 无 |
| 浮层出现 | 从 0.92 缩放 + 淡入，spring(0.85, 0.28) | 120 ms 淡入 |
| 浮层关闭 | 反向同路径，180 ms | 120 ms 淡出 |
| 翻页 | 旧页左移 24 px + 淡出、新页右移 24 px + 淡入并轻微去斜，180 ms | 100 ms 交叉淡化 |
| 答案揭示 | 中文 8 px 上浮 + 淡入，spring(1.0, 0.3) | 淡入 |
| 标注/划线落笔 | 路径从 0→100% 描出，140 ms | 直接显示 |

翻页与浮层动画用 `QPropertyAnimation` + `QEasingCurve.OutBack(s=0.9)` 近似 spring；若要求真实弹簧，使用 §9.6 的自实现 `SpringAnimator`（按 `damping/response` 生成临界阻尼曲线，可中断、可从当前值重定向）。

## 7. 算法设计

### 7.1 分页（行槽模型）

```python
ROWS_PER_PAGE = 9
WORDS_PER_ROW = 5

def build_slots(words):                      # 按 date_added 升序、created_at 升序
    slots = []
    for date, items in group_by_date(words):
        slots.append(("date", date, len(items)))
        for chunk in chunks(items, WORDS_PER_ROW):
            slots.append(("words", chunk))
    return slots

def paginate(slots):
    pages = [slots[i:i + ROWS_PER_PAGE] for i in range(0, len(slots), ROWS_PER_PAGE)]
    # 跨页续接：若某页首槽是 "words" 且其所属日期行在上一页，
    # 则在本页顶部插入 `("date", date, n, continued=True)` 并占用一个槽位（该页词行相应减少）
    return pages
```

规则：日期行占 1 槽；一组词若被页边界切开，续页顶部重复日期行并标注 `（续）`；页码从 1 开始，页脚显示 `P.{i} / {total}`。

### 7.2 加权随机排序（抽背顺序）

使用 **Efraimidis–Spirakis 加权无放回抽样**：对每个词生成键 `k_i = u_i ** (1 / w_i)`（`u_i ~ U(0,1)`），按键降序即得一次加权随机排列。特点：

- 一次生成整轮顺序，避免"抽到重复"的拒绝采样；
- 出现概率 ∝ 权重，但同一轮内不重复；
- 权重 1 的词仍有机会（不是永不出现），符合"划线=降权而非禁用"。

```python
def weighted_order(words):
    return sorted(words, key=lambda w: random.random() ** (1.0 / max(w.weight, 1)), reverse=True)
```

边界：权重钳制到 `[1, 10]`；单条直接返回；权重全等时退化为均匀随机。

### 7.3 抽背会话

- 进入抽背：取 `weighted_order` 全量，会话内指针递增，到末尾显示"本轮结束 · 再来一轮 / 只看没记住的"；
- 展示：英文（+音标）→ 用户点 `显示中文` → 揭示中文（+词性 +AI 摘要若有缓存）；
- 跨会话记忆：记录 `last_quiz_at`，下次进入优先补"久未抽到"的词（可选扩展）。

### 7.4 登记去重

- 归一化键：`word.strip().lower()`；已存在则提示"该词已登记（可编辑）"，不新增；
- 单词书里的词登记时，`source` 写入 `book:{book_id}:{no}`，并回写 `StudyRecord` 的 `registered=true` + `word_id`。

### 7.5 显示模式

枚举 `BOTH / EN_ONLY / CN_ONLY`；渲染时只改词格内部文本，不重建布局（保证翻页位置不跳）。持久化到 `data/settings.json`。

### 7.6 记忆状态机

```
未显示 ──显示──> 已显示 ──登记──> 已登记
   │                 │
   └──── 过滤：只背未显示过 ────────┘
                     └── 过滤：只背已登记 ──> 仅 registered=true
```

- `seen=true` 在词**首次**出现在背书卡片上时写入（不是点击"下一个"时）；
- `registered` 只由"登记到我的单词本"动作置真，取消登记不回落（保留历史，避免进度回退）。

## 8. AI 集成（DeepSeek）

### 8.1 端点与参数

| 项 | 值 |
| --- | --- |
| Endpoint | `POST https://api.deepseek.com/chat/completions` |
| Model | `deepseek-flash`（DeepSeek-V4.1-Flash-1017） |
| 推理等级 | `reasoning_effort: "low"`（映射表：minimal/low → low） |
| 思考模式 | `thinking: {"type": "enabled"}`（响应中 `reasoning_content` 单独返回，不入 UI 正文） |
| 输出格式 | `response_format: {"type": "json_object"}` |
| 其它 | 不使用 `temperature`（思考模式下该参数无效）；`max_tokens: 900`；`stream: false` |

### 8.2 报文（自拟）

```json
{
  "model": "deepseek-flash",
  "reasoning_effort": "low",
  "thinking": {"type": "enabled"},
  "response_format": {"type": "json_object"},
  "max_tokens": 900,
  "stream": false,
  "messages": [
    {
      "role": "system",
      "content": "你是资深英语词汇教练。只输出 JSON，不要 Markdown 代码块，不要多余文字。字段：translation_cn(字符串，微调中文释义), pos(词性), phonetic(IPA 音标), breakdown(词根词缀拆解，1-2 句), confusables(易混词数组，每项 {word, diff}), collocations(常见搭配数组，3-5 条), examples(例句数组，3 条，每项 {en, cn}), memory_tip(记忆钩子，1 句). 语言：解释用简体中文。"
    },
    {
      "role": "user",
      "content": "单词: abandon\n已登记中文: 放弃；抛弃\n词性: v.\n要求: 解释该词的词根含义、与近义词的差别，并给 3 个日常可用的例句。"
    }
  ]
}
```

### 8.3 响应处理

1. `choices[0].message.content` → `json.loads`；
2. 校验必需字段（`translation_cn`/`examples`），缺失字段用占位补齐，不整体报错；
3. JSON 解析失败 → 降级为纯文本展示（保留原文，标记"格式异常"）；
4. 401 → "API Key 无效，请到设置页更新"；402 → "账户余额不足"；429 → 5 s 后自动重试 1 次；5xx/超时 → 指数退避重试 2 次（1 s、3 s）；
5. 请求在 `QThread` 中执行，主线程只接信号。

### 8.4 缓存

- 键：`f"{word.lower()}|v{AI_PROMPT_VERSION}|{model}"`；
- 值：`{"ts": …, "data": {…}}`，写入 `data/ai_cache.json`，同时回填 `Word.ai`；
- 命中即秒开（面板直接渲染，不发请求）；面板提供 `重新生成`（强制刷新，覆盖缓存）。

### 8.5 密钥

- 优先级：环境变量 `DEEPSEEK_API_KEY` > `%USERPROFILE%\.real_wordbook\config.json`；
- 设置页输入后写入配置文件（权限尽力设为当前用户），UI 只显示 `sk-****{last4}`；
- 日志与异常消息中一律脱敏（`re.sub(r"sk-[A-Za-z0-9]{6,}", "sk-***", s)`）。

| 风险 | 影响 | 对策 |

| `deepseek-flash` 思考模式默认开启，响应含 `reasoning_content` | 解析取错字段 | 只取 `message.content`；`reasoning_content` 仅在调试日志中截断记录 |

| API Key 误入 git | 泄露 | `.gitignore` + pre-commit 钩子（可选）+ 提交前 `git status` 自查 |
