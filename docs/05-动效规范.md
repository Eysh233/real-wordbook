# RW-SPEC-003 动效规范

> 版本 v1.0 · 对应 `app/ui/motion.py` · 设计依据 Apple「响应、直接操控、可中断、空间一致性、材质、克制」

## 1. 为什么要有这一份

这个程序的界面是纸张与墨水的隐喻：翻页、抽卡、浮层。动效不是装饰，它回答三个问题：

1. **我点到了吗？** —— 按下即反馈，不等网络、不等重绘。
2. **东西从哪来、到哪去？** —— 浮层从被点的词格长出来，卡片从屏幕外滑进来。
3. **我现在能不能改主意？** —— 任何动画都能被下一次操作打断，并立刻朝新方向走。

## 2. 时长与曲线（唯一来源：`app/ui/motion.py`）

| 记号 | 值 | 曲线 | 用途 |
| --- | --- | --- | --- |
| `PRESS_MS` | 110ms | `OutCubic` | 任何按钮按下缩到 0.97 |
| `RELEASE_MS` | 170ms | `OutCubic` | 松手回弹到 1.0（略慢于按下，手感「有重量」） |
| `HOVER_MS` | 150ms | `OutCubic` | 词格悬停底色 0→16α |
| `POP_MS` | 190ms | `OutCubic` | 浮层出现：0.96→1.0 + 6px 上浮 + 淡入 |
| `POP_OUT_MS` | 120ms | `InCubic` | 浮层消失（快进快出，消失比出现快） |
| `PAGE_MS` | 210ms | `OutCubic` | 翻页：内容横向 18px + 淡入（出 110ms `InCubic`, -14px） |
| `SHEET_MS` | 240ms | `OutBack(1.06)` | 抽背卡入场：0.955→1.0 + 遮罩淡入 |
| `SWIPE_MS` | 170ms | `OutCubic` | 认识/不认识后卡片左右滑出，下一张从对侧滑回 |
| `TOAST_MS` | 200ms | `OutCubic` | Toast 淡入 + 8px 上浮（消失 160ms，-4px） |
| `STAGGER_MS` | 40ms | — | 单词书卡片列表逐张入场，最多错峰 6 张 |

**为什么是这些数**：Apple 的连续插值默认 0.3–0.4s 对应「界面元素的移动」；按钮反馈不属于移动而属于**状态**，所以压到 110/170ms——低于 100ms 用户感觉不到，高于 250ms 会觉得「卡」。浮层 190ms 接近 Apple 的 0.2s 弹出节奏。抽背卡是**新表面登场**，用 240ms 加轻微 overshoot（1.06）传达「落定」。

## 3. 三条不可违反的规则

1. **可打断**：`motion._run()` 以 `(widget, key)` 为键复用动画对象；同一个控件同一个属性永远只有一条动画在跑。新操作直接把旧的 `stop()` 掉，从**当前值**继续，不跳回起点。
2. **空间一致**：浮层的原点 `origin` 由被点的词格位置算出（水平取其中心比例，垂直判断是向上还是向下展开），所以它「从那个词长出来」，而不是从屏幕中央冒出来。
3. **减少动效**：`motion.set_reduced(True)` 时所有时长归零但**终态照旧**——布局、透明度、位置都到位，只是没有过渡。设置页「减少动效」复选框直接驱动它。

## 5. 被否决的候选（以及为什么）
| 候选 | 否决理由 |
| --- | --- |
| 卡片 3D 翻转（flip）翻页 | 只在切换瞬间有意义，且 600ms 以上必然拖慢连续翻页；纸张隐喻里「翻页」是滑动不是翻转 |
| 所有卡片统一的悬停放大 1.02 | 词格是密集网格，放大导致相邻格抖动；改为底色渐变，不改变几何 |
| 背景模糊（真实 Gaussian blur） | 桌面窗口内做全屏模糊要抓帧重绘，掉帧；浮层改用不透明度 + 描边表达层次 |
| Toast 从顶部滑入 | 视线在页面中部，顶部滑入会被顶栏遮挡且打断阅读；底部上浮更贴近手指位置 |
| 词条登记成功的撒花/弹跳 | 一天几十次的高频操作，超过 200ms 的庆祝动作会累积成噪音；改为 200ms Toast + 静默更新页码 |

## 6. Apple 设计原则映射

| 原则 | 本程序里的落点 |
| --- | --- |
| **响应（Response）** | 按下 110ms 就有缩放反馈，不等数据；点击词格立即出现选中描边环 |
| **直接操控（Direct manipulation）** | 词格就是可点的纸面；浮层贴在词下方，不跳到侧栏 |
| **可中断（Interruptible）** | 同属性动画复用同一对象；快速连点、快速翻页都从当前状态续接 |
| **空间一致性（Spatial consistency）** | 浮层原点取自词格；翻页方向与「下一页/上一页」一致；抽背卡从对侧滑回 |
| **材质与层次（Materials & depth）** | 纸页投影、浮层描边与淡底、遮罩 190α，靠「明度差 + 边界」而非模糊 |
| **克制（Restraint）** | 高频操作（悬停、按下）全部 ≤200ms；不用弹簧过冲，除了卡片入场那一次 1.06 |
| **可访问性（Reduced motion）** | 时长归零、终态保留；系统级 `reduced_motion` 开关贯穿全部组件 |

## 7. 翻页分层与标签菜单（第二次迭代）

### 7.1 翻页：三层不同步

翻页不再整页一起淡出，而是拆成三层各自带延迟与不同位移幅度（`notebook_view.py:_layer_progress`）：

| 层 | 出相（旧页离开） | 入相（新页到达） | 位移 |
| --- | --- | --- | --- |
| paper（纸面、装订脊、投影） | 固定不动 | 固定不动 | 0 |
| content（行线、日期、词格） | 立即出发 | 延迟 0.16 | ±22px |
| footer（页码、统计） | 固定不动 | 固定不动 | 0 |

- 时序：出相 110ms `EASE_IN` → 换页并发 `pageChanged` → 入相 210ms `EASE_OUT`。
- **纸页外框与页脚全程固定**：不淡、不位移、不缩放。翻页时只有「写在纸上的内容」在动，视线不会被整个页面晃到。
- 内容只滑不淡：词格统一挂在内容层 `self._content`（一个铺满视图的透明子控件）上，位移由 `_set_cell_shift()` 每帧 `move()` 这一个容器完成——**不再对 30 个词格逐个 `setGeometry`**，也不切换渲染路径，所以既没有「单词原地闪一下」，也不会因为逐格重排掉帧。
- 纸面（投影/纸纹/装订脊/孔/边线）按 `(尺寸, 主题, 缩放)` 缓存成 `QPixmap`，每帧只 `drawPixmap`；实测整窗重绘 3.75ms → 1.1ms。
- 切页瞬间新页直接站在入相起点（`switch()` 里先设 mode/progress 再重建词格），避免「先在原位渲一帧再跳出去」。
- 方向：`_turn_dir` 由目标页与当前页比较得出，出相往运动方向、入相从反侧滑回。

### 7.2 标签菜单

- 触发：点击顶栏 `TagMenu`（`#field` 造型：淡底 + 1px 描边 + 圆角 9），从按钮原点 `pop_in`。
- 层次：`Qt.Popup` 容器 + 内层圆角卡片 + 22px 投影；选中项用 accent 小圆点，而不是整行换色。
- 键盘：↑/↓ 移动、Enter 选中、Esc/Tab 关闭；点外部由 `Qt.Popup` 自动收起。
- 关闭：`pop_out` 120ms，随后 `close()`，不留残影。

## 8. 迷你悬浮窗（第三次迭代）

- **入场带弹性**：`geometry` 从 0.88 倍尺寸长到 1.0，300ms，`OutBack(overshoot 1.32)`；`windowOpacity` 0→1 用 165ms。弹一下是因为悬浮窗出现的语境是「叫出来看一眼」，落位要有点物理感，而不是凭空出现。
- **退场克制**：`geometry` 缩到 0.93，150ms `EASE_IN`，同时淡出；先动后隐，保留空间连续性（它从哪来就回哪去）。
- **毛玻璃**：`app/ui/acrylic.py` 走 Windows `SetWindowCompositionAttribute(WCA_ACCENT_POLICY)`，先试亚克力（state 4），老系统退到高斯模糊（state 3）；失败静默返回 False，绘制层照旧用半透明纸色（alpha 206）+ 上缘白色高光 + 1px 描边兜底。
- **拖拽**：拖动时清掉进行中的 `_geo_anim`，位置即拖即到（1:1 直接操控），松手后把新位置记为下一次入场的原点。
- `prefers-reduced-motion`：`motion.reduced()` 为真时入场/退场都退化成直接显示与隐藏。
