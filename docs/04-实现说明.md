# 实现说明（v0.1.0）

> 对应规范：[01-设计规范.md](01-设计规范.md)（RW-SPEC-001）、[02-单词书文件格式规范.md](02-单词书文件格式规范.md)（RW-SPEC-002）。
> 本文只记录「代码落地后与文档的差异、模块职责、验证方式」，需求本身仍以 01/02 为准。

## 1. 模块地图

```
main.py                     入口：High-DPI → QApplication → theme.qss() → MainWindow
app/config.py               路径、常量、权重、SRS 间隔、主题与显示模式枚举
app/models.py               Word / BookWord / Book / Settings（全部可 to_dict/from_dict）
app/storage.py              read_json / write_json_atomic（tmp→fsync→os.replace，先留 .bak）
app/repositories.py         WordsRepo / SettingsRepo / SecretRepo / BooksRepo / RecordsRepo / StatsRepo
app/services/paging.py      日期分节、行槽、分页、页脚日期标签
app/services/quiz.py        加权无放回排序、到期队列、SRS 复习推进、难度标记
app/services/book_parser.py md 单词书解析（YAML 头 + 表格 / 块两种格式）、校验、导出
app/services/ai_client.py   DeepSeek 报文构造、urllib 调用、错误中文化、结果缓存
app/services/tts.py         Windows SAPI 朗读（后台线程 + PowerShell）
app/services/csv_io.py      CSV 导入导出（utf-8-sig / gb18030 回退）
app/services/stats.py       连续天数、12 周热力图、汇总
app/services/roots.py       词根提取与聚合
app/ui/theme.py             三套主题 token + 全套 QSS + 字号缩放
app/ui/painter_utils.py     手绘荧光笔、划线抖动、纸纹、圆角投影
app/ui/widgets.py           Segmented / Toast / Card / Chip
app/ui/word_cell.py         单个词条（悬停、选中环、荧光笔、划线压字、权重角标）
app/ui/notebook_view.py     纸页、装订脊、行分隔线、日期行、页脚、翻页淡入
app/ui/action_popover.py    词条浮层：标注 / 划线 / 发音 / AI解释 / 编辑 / 删除
app/ui/card_session.py      抽背与背书共用卡片（揭晓、认识/不认识、登记、结算）
app/ui/book_panel.py        单词书列表与卡片
app/ui/stats_page.py        统计卡片 + 热力图
app/ui/settings_dialog.py   设置（Key、模型、推理等级、主题、显示模式、字号、减少动效）
app/ui/dialogs.py           登记 / 背书选项 / 词根 / 拼写测试
app/ui/ai_worker.py         AI 请求工作线程
app/ui/mini_window.py       桌面迷你悬浮窗
app/ui/main_window.py       顶栏、页面栈、所有信号连线与业务编排
```

依赖方向：`ui → services → repositories → storage/models → config`；`services` 不 import PyQt5，`ui` 不直接 `open()` 数据文件。

## 2. 与规范的有意偏差

| 项 | 规范 | 实现 | 原因 |
| --- | --- | --- | --- |
| 抽背卡片高度 | 0.68 × 窗口 | 0.50 × 窗口（上限 400px） | 原比例在 1240×860 下留白过多，内容因视觉重心偏移 |
| 浮层按钮 | 单行 6 个 | 两行 3 + 3 | 单行在 348px 宽度下文字过挤 |
| 浮层宽度 | 348 / 430 | 396 / 476 | 同上，保证「AI解释」按钮可读 |
| AI 面板高度 | 固定 250 | 96–300 按文档高度自适应 | 错误提示只有两行时大片空白 |
| Toast | 自动换行 | 单行 + 超宽省略 | 换行会让 `adjustSize()` 算出极窄宽度（已知 Qt 行为） |
| 主题 desk 色 | `#EBE3D3` | `#E5DAC6` | 与纸面区分度不足，页边看不出「书桌」 |
| 页脚日期标签 | 一律「今日登记」 | 仅当天说「今日」，其余「登记」 | 历史日期说「今日」是错的 |
| 日期行高度 | 占 1 个行槽 | 占 0.5 行（`config.DATE_ROW_RATIO`），9 行额度内 30 词一页 | 日期行原高度过半屏，压缩后一屏能看完整一天 |
| 英文单词字体 | Georgia 衬线 | `Segoe UI` 黑体（`theme.SERIF`） | 用户偏好黑体，衬线在深色下笔画易糊 |
| 默认字号 | 13 / 12.5 / 17 px | 统一乘 `FONT_BOOST = 1.12`，走 `theme.fs()` | 用户反馈整体偏小；`scale()` 仍只管间距 |
| 主题应用时机 | 构建 UI 后设主题 | **先** `theme.set_theme()` 再 `_build_ui()`；改设置走 `_rebuild_ui()` 整体重建 | 卡片在构造时取色，后设主题会留下浅色残留（深色下白块） |
| 控件覆盖面 | 只写了常用控件 QSS | 补 `QRadioButton`（含 indicator）、`QGroupBox`、`QListWidget`、`QScrollArea` 视口 | 单选按钮原本用系统黑字，深色下与背景融合 |

字号缩放只作用于 `theme.scale()` 计算出的像素值；布局按当前窗口尺寸实时计算，因此 940×620 与 1240×860 都可用。

## 3. 数据落盘

| 内容 | 路径 | 是否入库 |
| --- | --- | --- |
| 我的单词本 | `data/words.json` | 否 |
| 设置 | `data/settings.json` | 否 |
| AI 缓存 | `data/ai_cache.json` | 否 |
| 抽背统计 | `data/stats.json` | 否 |
| 单词书缓存 | `data/books/{book_id}.json` | 否 |
| API Key | `%USERPROFILE%\.real_wordbook\config.json` | 否（另有 `DEEPSEEK_API_KEY` 环境变量优先） |
| 单词书原件 | `StudyBook/{book_id}.md` | 是 |
| 记忆进度 | `StudyRecord/{book_id}.json` | 否 |

所有 JSON 写入均为原子写，并在覆盖前留一份 `.bak`；读取失败自动回退 `.bak`。

## 4. 验证

```bash
python tests/smoke_ui.py      # 10 组离屏回归：登记/浮层/权重/搜索/抽背/单词书/主题/迷你窗/标签
python tests/seed_demo.py     # 生成 29 词演示词库 + 导入 StudyBook 里的示例书
python tests/render_shots.py  # 离屏渲染各界面到 docs/shots/（调排版用，不入库）
```

冒烟测试会先把 `config` 的全部路径改写到临时目录，不会碰真实词库。

## 5. 已知边界

- TTS 走 Windows SAPI（`System.Speech`），非 Windows 平台 `tts.available()` 为 False。
- AI 功能需要用户在设置页填 Key；无 Key 时浮层给出可操作的提示，不阻断其它功能。
- 未实现（F8/F9/F12 未选）：错词本、自动备份、单元测试与 exe 打包。
- 单词书解析器实现了 02 号规范的全部必填列与两种书写格式，但未支持 HTML 表格与多表合并。
